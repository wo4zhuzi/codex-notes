# 外部工具使用笔记

本目录记录可辅助 AI 编程的外部工具。这里的“外部工具”指独立于 Codex CLI 本身、但可以通过命令行、MCP server 或配置文件增强 AI 编程体验的工具。

## 目录定位

- 安装方式：如何安装工具本体，以及需要哪些本地前置条件。
- 基础使用：不用 AI 时，开发者如何直接通过 CLI 验证工具可用。
- MCP 接入：如何把工具能力暴露给 Codex。
- 文件与缓存：工具会在项目中生成哪些本地文件，哪些应该加入 `.gitignore`。
- AI 使用边界：什么时候让 AI 调用工具，什么时候应由用户或 CI 控制。

## 当前工具

| 工具 | 文档 | 适用场景 |
| --- | --- | --- |
| CodeGraph | [codegraph.md](./codegraph.md) | 为代码库建立函数级依赖图，让 AI 查询符号、调用链、影响面和结构上下文。 |

## 推荐文档结构

新增外部工具文档时，优先使用以下章节：

```markdown
# <工具名> 使用笔记

## 结论
## 解决什么问题
## 安装方式
## 基础使用
## 与 Codex / MCP 集成
## 本地文件与 gitignore
## 什么时候让 AI 使用
## 常见问题
```

工具文档应使用简体中文说明，保留工具名、命令名、配置键和模型名的英文原文。不要写入真实 API Key、个人 Token、私有代理地址或内部服务 URL。
