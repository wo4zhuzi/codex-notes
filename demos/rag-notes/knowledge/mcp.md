# MCP

MCP 是 Model Context Protocol，用来让 AI 客户端以统一协议访问外部工具、资源和提示词。

在 AI 编程工具中，MCP server 可以暴露文件检索、数据库只读查询、CodeGraph、文档服务等能力。客户端通过 MCP 调用这些能力，而不是直接理解每个工具的内部实现。

MCP 和 RAG 的关系：

- MCP 是工具和上下文接入协议。
- RAG 是检索增强生成架构。
- MCP 可以作为 RAG 的检索入口，例如通过 MCP 查询文档、代码图谱或数据库。

如果多个 AI 客户端要复用同一组工具能力，MCP 比把工具逻辑写死在单个应用里更合适。
