# Function Calling

Function Calling 适合让模型把自然语言转换成结构化函数调用参数。

模型不会真的执行函数。它只返回函数名和 JSON 参数，应用程序负责执行真实函数、接口或数据库查询，再把执行结果回传给模型。

典型链路：

```text
用户问题
-> 模型判断需要调用哪个函数
-> 模型返回 function_call
-> 应用执行本地函数
-> 应用把函数结果回传模型
-> 模型生成最终回答
```

Function Calling 和 RAG 的区别：

- Function Calling 重点是调用受控业务动作或查询接口。
- RAG 重点是先检索知识资料，再基于资料生成答案。
- 两者可以组合，例如先用函数查订单，再用 RAG 查售后政策。
