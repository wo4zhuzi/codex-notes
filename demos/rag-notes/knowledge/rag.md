# RAG 入门

RAG 是 Retrieval-Augmented Generation，也就是检索增强生成。

在项目中，RAG 的作用是让模型回答前先检索外部知识，再把相关内容作为上下文交给模型。这样可以减少模型凭记忆编造答案的问题。

最小 RAG 链路：

```text
用户问题
-> 检索知识库
-> 取出相关片段
-> 把片段放进 prompt
-> 模型基于片段回答
```

这个 demo 使用本地 Markdown 文件作为知识库，使用关键词评分作为检索方式。它能展示 RAG 的核心链路，但还不是生产级向量 RAG。

生产系统通常会加入 embedding、向量数据库、BM25、reranker、权限过滤、引用来源和评估指标。
