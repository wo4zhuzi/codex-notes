# GPT-5.6 与 Superpowers 兼容性调整计划

## 目标

基于现有 Superpowers Skill 的实际规则定位其与 GPT-5.6 的冲突机制；按用户最终决定直接卸载四个独立安装的 Superpowers Skill，并在仓库文档中记录原因、验证结果和风险边界。

## 当前阶段

- 状态：完成
- 当前动作：等待用户决定是否提交；不得自动归档 `.planning/current/`

## 阶段

1. [完成] 调查现有 Skill、仓库文档、Git 状态和可验证冲突
2. [完成] 用户确认直接删除四个 Skill，不保留备份
3. [完成] 删除用户级 Superpowers Skill 目录并检查安装目录
4. [完成] 更新 Skill 文档和日期变更记录
5. [完成] 执行卸载检查、文档检查和 Git 差异检查

## 根因定位要求

- 区分“模型能力升级导致的协议冲突”和“具体版本不可用”两类问题。
- 以现有 Skill 中的强制门槛、顺序约束、重复规划和工具要求为证据。
- 不把未经验证的 GPT-5.6 产品细节写成官方事实。

## 验证方式

- 检查四个 Superpowers Skill 目录均不存在。
- 检查 Markdown 链接、占位符、疑似密钥和 Git 差异。

## 风险边界

- 不修改与 Superpowers 兼容性无关的文档或 Skill。
- 不覆盖用户已有未提交改动。
- 仅删除用户明确指定的四个 Superpowers Skill，不影响其他个人或系统 Skill。
- 不声称存在未经官方材料证实的 GPT-5.6 兼容性结论。
